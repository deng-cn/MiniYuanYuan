# `BiCrossGateFFN` 12M 架构公平对比与 372 题盲测详细报告（`arena_1127`）

> 本文档完整记录了在单卡 **RTX 3070 8GB** 上围绕自研前馈架构 **`BiCrossGateFFN`（接法 B）** 开展的 `arena_1127` 公平对比实验，涵盖架构数学定义、负消融验证、算力与显存账本、全量 `3,458` 条留出验证集 CE，以及 `372` 道未见题逐题打分结果与原文对照。所有数据均经实测核验，配套代码与配置文件均已收录于本仓库 `moxing/` 与 `configs/` 目录，可直接复现。

---

## 核心结论速览

1. **同参数、同算力、甚至同等验证集 CE 下，`BiCrossGateFFN` 在实战生成上持续胜出传统 `SwiGLU`**
   - 在 `d=192, L=16` 完全同构型下，**7 号（纯 `BiCrossGate`）** 与 **6 号（纯 `SwiGLU`）** 的参数量完全相同（`12,021,568`）、单 token 前向算力完全相等（`30.71 MFLOPs/tok`）、2 Epoch 总训练算力完全相等（`19.876 PFLOPs`）、全量留出集 CE 也完全相等（`2.2407`）；但在 372 题盲测实战中，**7 号以 `407 vs 400`（`54.7% vs 53.8%`，`64 胜 / 254 平 / 54 负`）拿到全场最高分**。
2. **极小参数下的反直觉规律：全局 Loss 最低 ≠ 指令理解与定位最强**
   - 在 `d=256, L=10` 构型下，**4 号（纯 `BiCrossGate`）** 全局留出 CE 略高于 1 号（`2.2148` vs `2.2061`），但在 **36 题非知识型任务（带资料定位、总结概括、情绪对话、能力边界）** 上直接打出 **`72.2% vs 54.2%`（`52/72` vs `39/72`，`+18.0` 个百分点）** 的断层领先。
3. **双极性门控是核心机制（3 号负消融实证）**
   - 3 号（`BiCrossV2`）对 `gate` 外加 `SiLU` 并引入残差旁路“温和化”后，正负双向调节被削弱，表现退化回接近传统 `SwiGLU`，反证了原始 `BiCrossGateFFN`（不加外部激活）的有效性。
4. **“宽浅 vs 深瘦”工程选型法则**
   - 因 `BiCrossGateFFN` 参数含 $2d^2$ 二次项，将隐藏维从 `256` 降至 `192` 并加深到 `16` 层后，其 FFN 扩展倍率得以从 `2.66×` 释放至 `3.25×`：
     - 追求**非知识型推理 / RAG 定位 / 概括 / 边界遵循** → 选 **4 号（宽浅 `d256 L10` 纯 `BiCrossGate`）**；
     - 追求**综合最高分 + 压缩 0 分翻车 + 均衡知识记忆** → 选 **7 号（深瘦 `d192 L16` 纯 `BiCrossGate`）**（已学知识类得分由 `41.7%` 跃升至 `55.6%`，0 分翻车由 9 题压至 **1 题**）。

## 一、`BiCrossGateFFN`（接法 B）架构原理与数学分析

### 1.1 前向计算定义

传统 `SwiGLU` 的门控支路仅做一阶线性投影加 `SiLU`（$\text{SiLU}(W_{\text{gate}} x) \odot W_{\text{up}} x$）。`BiCrossGateFFN` 则先构造**双分支二阶逐元素交叉特征**，再直接映射为**双极性（正负双向）宽维门控**：

```python
# 实现位置：moxing/model_p4.py -> BiCrossGateFFN
# 1) 双分支二阶交叉特征（输出 2d 维）
q1, q2 = self.q(x).chunk(2, dim=-1)                  # W_q: d -> 2d (无 bias)
b_feat = torch.cat((F.gelu(q1 * x), F.silu(q2 * x)), dim=-1)

# 2) 双极性交叉门控 × 升维仓库 -> 降维输出
gate = self.gate_proj(b_feat)                        # W_gate: 2d -> i (不加外部 SiLU)
y = self.down_proj(gate * self.up_proj(x))           # W_up: d -> i, W_down: i -> d
```

### 1.2 与标准 `SwiGLU` 的参数量与算力对照

| 对比维度 | 标准 `SwiGLU` | `BiCrossGateFFN`（接法 B） | 工程含义 |
|---|---|---|---|
| **单层 FFN 参数量** | $3 d \cdot i$ | $2 d^2 + 4 d \cdot i$ | 存在 $2d^2$ 二次项；相同参数预算下，降低隐藏维 $d$（如 `256 → 192`）可显著提高扩展倍率 $i/d$ |
| **单层 FFN 前向 FLOPs/tok** | $6 d \cdot i$ | $4 d^2 + 8 d \cdot i$ | 与同参数量配置的 `SwiGLU` 理论计算量几乎完全一致（`d192 L16` 下相差 `0.00%`） |
| **门控极性** | 非负偏向（`SiLU` 压制负半轴） | **双极性（正负双向调节）** | 允许对知识仓库通道同时执行“正向增强”与“反向抑制/翻转” |
| **残差初始化缩放** | $\text{std} = \frac{0.02}{\sqrt{2L}\sqrt{i/d}}$ | 同左（作用于 `o_proj` 与 `down_proj`） | 保持深层（`L=16`）训练梯度稳定（`resid_init_scale = true`） |

### 1.3 为什么必须保持“双极性”：3 号（`BiCrossV2`）负消融验证

为了验证 `BiCrossGateFFN` 的收益究竟来自“高阶双极性门控”还是仅仅来自额外的非线性变换，我们在同构型（`d256 L10`，`12.02M`）下设计了 **3 号消融对照（`moxing/model_bicross_v2.py`）**：对门控输出外加 `SiLU` 并加入残差旁路以“温和化”门控分布。

实测表明，3 号虽然把验证集 `best_val` 从 4 号的 `2.2493` 拉回至 `2.2421`（贴近 1 号 `SwiGLU` 的 `2.2404`），但也同步抹平了双极性门控带来的定位/概括增益，整体退化回接近普通 `SwiGLU`。这从反面证明：**去掉外部 `SiLU`、保留无压制的双极性二阶交叉门控，正是该架构的核心机制。**

### 1.4 统一注意力与骨架底座

全部 7 位选手除 2 号（`DiffQ Pool` 注意力对比，已淘汰）外，均采用完全一致的现代注意力底座（`StandardGQAAttention`）：
- **标准 2-KV GQA**：独立 `q_proj`、`k_proj`、`v_proj`、`o_proj`（全无 bias），每头 `hd = 32`（`d=256` 时 `8Q/2KV`，`d=192` 时 `6Q/2KV`）；
- **稳定组件**：`q_norm` / `k_norm`（`RMSNorm`, `eps=1e-6`）、半维原生 dtype RoPE（`rope_theta = 1e6`）、原生 `cuDNN SDPA`；
- **词表与输出头**：`vocab_size = 8,302`（`corpus/vocab_v2.json`），`tie_word_embeddings = true`，关闭 MTP（`mtp = 0`）。

## 二、公平实验流程与 7 位选手配置清单

### 2.1 统一实验底座（`arena_1127`）

- **训练与验证语料**：
  - 由新版主力语料 `1123`（`460,073` 条 / `87.91M` 字，打包占比 `72.7%`）与旧版干净语料 `1101`（`225,858` 条 / `33.07M` 字，打包占比 `27.3%`）混合构成；
  - 合计 **`685,931` 条 / `120.98M` 字 / `108.40M` tokens**，打包为 `99,146` 个训练窗口与 `482` 个验证窗口（对应显式留出的 `3,458` 条 `val-` 原分布测试样本，共 `310,931` 助手计损 tokens）。
- **统一训练超参（单卡 RTX 3070 8GB）**：
  - 窗口与批次：`max_len = 1088`、`batch = 8`、`grad_accum = 2`（每步 `16` 窗 = `17,408` tokens）；
  - 步数与总量：`epochs = 2`（`6,196` steps/epoch，合计 **`12,392` steps ≈ `2.157 亿` 训练 tokens**）；
  - 优化与调度：`AdamW (betas=(0.9, 0.95), eps=1e-8, weight_decay=0.1)`（1D/Norm 免衰减），`lr = 4e-4`、`warmup = 150`、Cosine 衰减至 `5%`（`2e-5`），`grad_clip = 1.0`；
  - 精度与随机种子：`bf16` + `attn_backend = cudnn` + `seed = 2027`。

### 2.2 实验推进脉络（两阶段 2×2 对照）

1. **第一阶段（`d256 L10` 宽浅擂台，1～4 号）**：在相同 `12.0M` 参数下对比传统 `SwiGLU`（1 号）、`DiffQ`（2 号）、`BiCrossV2` 消融（3 号）与纯 `BiCrossGate`（4 号）。发现 4 号在非知识型理解任务上断层领先，但受限于 `2d²` 二次项导致 `i/d` 仅 `2.66×`，常识记忆偏薄、0 分复读偏多。
2. **第二阶段（`d192 L16` 深瘦 2×2 扩容验证，5～7 号）**：为检验降低 $d$ 释放 `BiCrossGate` 宽度的理论预期，将构型拉深变瘦至 `d=192, L=16`，使 `BiCrossGate` 扩展倍率由 `2.66×` 提升至 **`3.25×`（`i=624`）**，并与同参数完全相等的交替混合（5 号）及纯 `SwiGLU`（6 号，`i=960, 5.00×`）正面同台评测。

## 四、372 道未见题盲测全面评测

### 4.1 评测口径

- **题库构成（共 372 道全未见新题）**：
  - **纯盲测 300 题（`blind_100x3`）**：覆盖 100 个日常/常识/换算/生活场景，每类 3 题；
  - **已学类新题 72 题（`learned_24x3`）**：对应训练集 24 个大类各出 3 道全新题，细分为 **非知识型 36 题**（定位、概括、日常对话、边界拒答、故事理解、改写）与 **已学知识/常识/物性 36 题**。
- **解码参数**：全部模型统一 `greedy` 解码（`temperature = 0.0`, `max_new_tokens = 96`, `repetition_penalty = 1.08`, `no_repeat_ngram_size = 4`）。
- **逐题打分标准（0 / 1 / 2 分，满分 2 分）**：
  - `2 分`：事实基本正确、切中题意、语言完整通顺；
  - `1 分`：句子可读但事实错误、答偏、退化为抄首句或存在局部瑕疵；
  - `0 分`：乱码、自相矛盾、严重复读循环、胡言乱语或身份错乱。

## 六、工程选型建议与复现命令

### 6.1 选型规律

| 目标场景 | 推荐构型 | 核心原因 |
|---|---|---|
| **RAG 资料定位 / 概括 / 能力边界 / 情绪对话** | **4 号（宽浅 `d256 L10` 纯 `BiCrossGate`）** | 更宽的残差流 + 双极性二阶门控，非知识型 36 题拿到 `72.2%` 断层第一，且吞吐高达 `90.6k tok/s` |
| **综合均衡 / 压缩 0 分崩坏 / 兼顾常识记忆** | **7 号（深瘦 `d192 L16` 纯 `BiCrossGate`）** | 降低 $d$ 压缩 $2d^2$ 开销，释放 `3.25×` FFN 扩展倍率，372 题总分 `407/744` 全场第一，知识类 0 分仅 1 题 |
| **极速基线对照** | **1 号（宽浅 `d256 L10` 纯 `SwiGLU`）** | 吞吐最高（`101.3k tok/s`），适合做标准 Transformer 对照组 |

### 6.2 复现训练命令

在按主 `README.md` 准备好打包数据目录（如 `dataset/arena_1127`）后，可直接用统一入口 `tools/train_arena.py` 复现任意选手：

```bash
# 1 号：d256 L10 纯 SwiGLU 基线（12.06M）
python tools/train_arena.py --config configs/p3_d256_l10_stdgqa_kv2_swiglu1080_w1088.json --data dataset/arena_1127 --run arena_p1_swiglu --out out --batch 8 --grad-accum 2 --max-len 1088 --lr 4e-4 --epochs 2 --dtype bf16 --seed 2027

# 4 号：d256 L10 纯 BiCrossGate 宽浅构型（12.04M，非知识型王者）
python tools/train_arena.py --config configs/p4_d256_l10_stdgqa_kv2_bicrossgate680_w1088.json --data dataset/arena_1127 --run arena_p4_bicross --out out --batch 8 --grad-accum 2 --max-len 1088 --lr 4e-4 --epochs 2 --dtype bf16 --seed 2027

# 6 号：d192 L16 纯 SwiGLU 深瘦基线（12.02M）
python tools/train_arena.py --config configs/p6_d192_l16_stdgqa_kv2_swiglu960_w1088.json --data dataset/arena_1127 --run arena_p6_swiglu_l16 --out out --batch 8 --grad-accum 2 --max-len 1088 --lr 4e-4 --epochs 2 --dtype bf16 --seed 2027

# 7 号：d192 L16 纯 BiCrossGate 深瘦构型（12.02M，全场综合冠军）
python tools/train_arena.py --config configs/p7_d192_l16_stdgqa_kv2_bicrossgate624_w1088.json --data dataset/arena_1127 --run arena_p7_bicross_l16 --out out --batch 8 --grad-accum 2 --max-len 1088 --lr 4e-4 --epochs 2 --dtype bf16 --seed 2027
```
