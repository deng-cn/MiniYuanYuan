## loss 低不等于会答题

同一批权重做过三组能力测试，结论比 loss 难看，但真实：

| 测试 | 结果 |
|---|---|
| 45 题人工判分（旧 1124 版，24.87M） | 全对 3 题、半对 4 题；失败样本几乎都是「主题词 + 模板拼接」 |
| 开卷复现（给原文，测逐字命中） | 36.8% |
| 闭卷复现（不给原文，测逐字命中） | 4.0%，与随机同级 |
| 同一句话在训练集出现 4,978 次后的条件 CE | 2.05（仍未压到「背下来」的水平） |

结论：30M 参数这个量级学到的是**语言形状**（句式、语气、问答节拍、该在哪儿收口），
不是**内容**。想让它记住事实，扩参数或外挂检索，二者必选其一。
